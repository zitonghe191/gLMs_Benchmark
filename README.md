# DNA Language Model Benchmark

A toolkit for benchmarking DNA language models on sequence-level classification
tasks. For a given `(task, model)` pair it extracts mean-pooled embeddings from
every selected layer of a pretrained model, trains a small MLP probe on those
embeddings, and reports classification metrics. A separate module,
[`layer_corr/`](layer_corr/), analyses representation similarity between layers,
across datasets, and across models.

## Repository structure

```
.

│   ├── models.yaml           #   adapters, HF ids, layers, MLP widths
│   └── tasks.yaml            #   readers, data dirs, classifiers, per-model overrides
├── dnabench/                 # benchmark pipeline: extract features, train probes
│   ├── adapters.py           #   model loaders (DNABERT-2, GENA-LM, GROVER, NTv2, HyenaDNA)
│   ├── readers.py            #   dataset readers -> units (single_csv / paired_csv / paired_fasta)
│   ├── extract.py            #   per-layer feature extraction
│   ├── trainers.py           #   MLP probe training + metrics
│   ├── runner.py             #   orchestration (extract + train)
│   ├── config.py             #   YAML-driven plan resolution
│   ├── env.py                #   seeds, environment, mean pooling
│   ├── __init__.py
│   └── HyenaDNA_*/           #   optional local checkpoints (see models.yaml)
├── data/                     # task datasets as CSV/FASTA
│   ├── Promoter/             #   (also: TFBS, Methylation, Splice_site, EPI,
│   ├── CTCF_loops/           #    Yeast, Fungi_Virus, 2kb_promoter, Random)
│   └── ...
├── layer_corr/               # representation-similarity analysis
│   ├── core.py               #   generic engine (no project dependencies)
│   ├── config.py             #   paths, models, BUILD_PRESETS
│   ├── build_matrices.py     #   per-(model, dataset) layer-similarity cache
│   ├── cross_dataset_corr.py #   fingerprint correlation across datasets
│   ├── layer_centroids.py    #   per-layer class centroids, same-layer cosine
│   ├── fingerprint_panels.py #   fingerprint-correlation panels
│   ├── cross_domain_panels.py #  cross-domain fingerprint panels
│   ├── cross_network_cka.py  #   linear CKA between networks
│   └── cache/                #   generated caches (git-ignored)
├── make_data/                # dataset generators
│   ├── gen_random_csv.py
│   └── dataset_generator_2kb_promoter.py
```

Per-run outputs — `{model_dir}/features/…` and `{model_dir}/results/…` — are
generated by `dnabench` and are not shown above.

## Installation

```sh
pip install torch transformers scikit-learn pandas numpy pyyaml tqdm
```

`make_data/dataset_generator_2kb_promoter.py` additionally needs Biopython.

## Configuration

Everything is driven by two YAML files under `configs/`:

- **`models.yaml`** — one entry per model: `adapter` (which loader to use),
  `tag` (used in feature directory names), `hf_id`, `layers` (which layers to
  extract), and `hidden_dims` (MLP widths). Optional `model_dir` / `local_cache`
  point at a local checkpoint.
- **`tasks.yaml`** — one entry per task: `reader` (`single_csv` / `paired_csv` /
  `paired_fasta`), `data_dir`, `classifier` (`binary` / `multiclass`),
  `num_classes`, and optional `model_overrides` (e.g. different `hidden_dims` or
  `layers` for a specific model on this task).

Set the real `data_dir` values in `tasks.yaml` — they ship as
`/path/to/your/data/file` placeholders.

Supported models: DNABERT-2, GENA-LM, GROVER, Nucleotide-Transformer-v2
(50m / 250m), HyenaDNA (128 / 256 / small). Each adapter loads the model
truncated to the requested number of layers and mean-pools hidden states with the
attention mask.

## Usage

Extract features and train the probe in one call:

```python
from dnabench.runner import run

run(
    task="Promoter",
    model="DNABERT-2",
    max_length=128,
    batch_size=64,
    train_batch_size=64,
    stage="all",       # "extract" | "train" | "all"
    base_dir=None,     # defaults to <repo>/<task>/<model>
)
```

The same is reachable through CLI flags via `main()`:

```sh
python -c "from dnabench.runner import main; main()" \
    --task Promoter --model DNABERT-2 \
    --max_length 128 --batch_size 64 --train_batch_size 64 --stage all
```

## Feature directory layout

`dnabench/extract.py` writes, per layer `L` and per dataset unit:

```
{base_dir}/features/{tag}_layer{L}/{unit}/all_features.npy
{base_dir}/features/{tag}_layer{L}/{unit}/all_labels.npy
```

- `all_features.npy` — `(n_samples, hidden_dim)` mean-pooled embeddings.
- `all_labels.npy` — `(n_samples,)` integer labels.

Training (`dnabench/runner.py:train_main`) discovers these directories, runs
5-fold cross-validated training per `(layer, unit)`, and writes
`{base_dir}/results/mean_results.csv`.

## layer_corr

Representation analysis, independent of training:

- `core.py` — generic engine (`Layout`, cosine similarity, linear CKA,
  fingerprints, cache I/O); imports nothing from this project, so it can be
  reused elsewhere with a different `Layout`.
- `config.py` — this project's data paths, layer/model definitions, and
  `BUILD_PRESETS` (named build configurations).
- `build_matrices.py` — builds a per-`(model, dataset)` layer-similarity matrix
  cache under `cache/`; e.g. `get_matrices(datasets=..., **C.BUILD_PRESETS["coldwater"])`.
- `cross_dataset_corr.py` — fingerprint correlation across datasets.
- `layer_centroids.py` — per-layer class centroids and same-layer cosine.
- `fingerprint_panels.py` — fingerprint-correlation panels over a set of datasets.
- `cross_domain_panels.py` — cross-domain fingerprint panels.
- `cross_network_cka.py` — linear CKA between networks at their middle layer.

Set the `BASE_*` paths in `layer_corr/config.py` to your feature directories.
Note that layer directory naming is irregular across datasets, so a dataset with
a new naming scheme needs its own entries there.

## make_data / NT_attention

- `make_data/gen_random_csv.py` — generates the `Random` control datasets.
- `make_data/dataset_generator_2kb_promoter.py` — builds the 2kb promoter dataset
  (adapted from GENA-LM's downstream generator).
- `NT_attention/extract_attention*.py` — dump NTv2 attention maps (`*_attn.npy`)
  and sequences (`*_seqs.npy`) for visualisation.

## Notes

- `dnabench/env.py` sets deterministic seeds and `CUBLAS_WORKSPACE_CONFIG`, and
  defaults `HF_ENDPOINT` to a Hugging Face mirror; it runs on `import dnabench`.
